# Yunjia Zhang — Academic Homepage

Personal academic website for **Yunjia Zhang (张耘嘉)**.

**Site:** https://river505.github.io

## Features / 功能

- Classic, responsive academic homepage / 简洁响应式学术主页
- English–Chinese language toggle with saved preference / 中英切换并记住语言偏好
- Research, publications, projects, experience, and contact / 研究方向、论文、项目、经历与联系方式
- Google Scholar profile and publication links / Google Scholar 学术成果链接

## Deployment / 部署

This site is a standalone static `index.html`. In the GitHub repository's **Settings → Pages**, choose **Deploy from a branch**, then **main / (root)**. GitHub Pages will serve it at the URL above.

这是一个纯静态页面，无需构建。进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，再选择 **main / (root)** 发布。

## Content note / 内容说明

Google Scholar citation metrics are a snapshot provided in November 2026. They are not automatically refreshed. Publication titles are preserved in their published form.

Google Scholar 引用指标为 2026 年 11 月的快照，不是实时统计；论文标题保留正式英文名称。
